Chromecast Setup & Browser Configuration
Google's Cast Web SDK requires a secure origin to discover and connect to Chromecast devices. By configuring your browser to treat your Rainy network URL as secure, casting works seamlessly over HTTP with zero certificates or warnings.
Your Rainy Server Origin
Copy this address to paste into your browser's secure origin flag.
http://...:6969
Browser Setup Instructions
Google Chrome / Brave / Vivaldi / Opera
  1. Open chrome://flags/#unsafely-treat-insecure-origin-as-secure in a new tab.
  2. Paste your Rainy URL (http://...:6969) into the Insecure origins treated as secure text box.
  3. Change the dropdown setting from Disabled to Enabled.
  4. Click Relaunch at the bottom of the browser.
Microsoft Edge
  1. Open edge://flags/#unsafely-treat-insecure-origin-as-secure in a new tab.
  2. Paste your Rainy URL (http://...:6969) into the text box.
  3. Set to Enabled and click Restart.
Localhost Shortcut
When listening directly on the host machine using http://localhost:6969, browsers automatically treat localhost as a secure context with zero configuration needed.
Firefox / Safari Note
The Google Cast Web Sender API is a Chromium-exclusive browser API. To cast music to a Chromecast device, please use Chrome, Edge, Brave, Vivaldi, or Opera.
